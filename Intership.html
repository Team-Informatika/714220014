Pengalaman Magang

PLN UP2D Jawa Barat

Posisi: IT Support & Tim Media

🖥️ IT Support 🎬 Tim Media

Selama menjalani program magang di PLN UP2D Jawa Barat, saya berperan sebagai IT Support dan bagian dari Tim Media. Pada peran IT Support, saya bertanggung jawab membantu pemeliharaan sistem komputer, troubleshooting perangkat keras dan perangkat lunak, serta memastikan kelancaran operasional teknologi di lingkungan kerja.

Selain itu, sebagai Tim Media, saya terlibat dalam kegiatan dokumentasi dan pembuatan konten visual seperti fotografi dan videografi untuk mendukung kebutuhan publikasi perusahaan. Saya juga berkontribusi dalam pengolahan konten agar lebih menarik dan informatif untuk berbagai media digital.

Pengalaman ini memberikan saya pemahaman yang lebih luas tentang dunia kerja profesional, meningkatkan kemampuan teknis di bidang IT, serta mengasah kreativitas dalam produksi konten digital.

PLN UP2D Jawa Barat

Posisi: K3L Support & Tim Media

🦺 K3L Staff 🎬 Tim Media

Selama menjalani program magang di PLN UP2D Jawa Barat, saya berperan sebagai K3L Staff (Keselamatan, Kesehatan Kerja, dan Lingkungan) serta bagian dari Tim Media. Pada peran K3L, saya bertanggung jawab membantu penerapan budaya keselamatan di lingkungan kerja, mulai dari pemantauan kepatuhan terhadap prosedur K3, pemeriksaan penggunaan alat pelindung diri (APD), hingga pendataan dan pelaporan kegiatan K3L secara rutin.

Selain itu, sebagai Tim Media, saya terlibat dalam kegiatan dokumentasi dan pembuatan konten visual seperti fotografi dan videografi untuk mendukung kebutuhan publikasi perusahaan, termasuk konten sosialisasi dan kampanye keselamatan kerja. Saya juga berkontribusi dalam pengolahan konten agar lebih menarik dan informatif untuk berbagai media digital.

Pengalaman ini memberikan saya pemahaman yang lebih luas tentang dunia kerja profesional, khususnya pentingnya keselamatan dan kesehatan kerja di lingkungan industri ketenagalistrikan, serta mengasah kreativitas dalam produksi konten digital.
